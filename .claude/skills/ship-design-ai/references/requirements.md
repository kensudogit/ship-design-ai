# 要件チェックリスト

## 入力

- 船種・積載能力・設計速力・航路・海象・喫水制限
- Lpp / B / T / D / Cb / Cp、密度 1.025 t/m³、単位 m・kn・t
- 案件要件: 目標 ∇、目標 DWT、速力、航程、最大幅、最大喫水、旧パナマ閘門の強制

## 機能

- 案件登録、要件保存、候補生成、評価、制約チェック
- 制約優先の多目的探索、パレート比較、3D、Markdown レポート、設計者レビュー
- 仕様抽出・説明（LLM）。物理計算は geom-v3

## 非機能

- 監査証跡、モデル再現性（`geom-v3` + seed）
- デモは認証なし（OPEN-10）。本番で権限・秘密情報・ジョブ分離
- API 応答・探索時間は実測して SLO を確定

## 受入条件

- 不正入力の 422、既知船型の ∇ 回帰、単位の整合、seed 再現
- Holtrop/ITTC・DWT・GM 指標を実測・船級と呼ばない
- 安全未評価項目を明示し、採用は設計者レビュー経由
